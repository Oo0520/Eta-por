# Eta 测试版 · 测试协议与免责声明

版本：3.4.0-beta.1（测试线）
适用：以 `io.github.mangi.eta.beta` 包名分发的测试版，与正式版 Eta 相互独立、数据不互通。
生效：你在首次启动页勾选同意后生效；条款更新会让同意重新征询。

## 一、这是测试版

1. 本版本用于功能验证与问题排查，不是正式发布版本；界面、功能、数据格式都可能在后续版本中变更或删除。
2. 升级、降级、卸载都可能造成本地数据丢失。请在做任何测试动作前，用「设置 → 数据备份」导出一次全量备份。
3. 测试版与正式版是两个独立应用：会话、人物卡、知识库、简历库、MCP 配置、自动任务都不会自动同步。两个包各自的数据需要你手工导出、导入。
4. 测试版可能随时停止分发，不承诺持续维护。

## 二、AI 输出的性质与验证义务

1. 助手的回答与操作由概率模型生成，可能出现错误、遗漏、过时信息，或编造并不存在的内容（通常称为「幻觉」）。这是这类产品的正常现象，不是偶发缺陷。
2. 你有验证义务：涉及金额、账号、合同、健康、法律、税务、行程、他人权益的内容，必须由你自行核实后使用。
3. 助手输出不构成法律、医疗、财务、税务等专业意见，也不能替代相应资质人员的判断。
4. 对不可逆操作（转账、支付、删除文件、发送消息、修改系统设置、安装或卸载应用等），助手执行前会尽量请求确认；但你必须自己复核，不能把「助手已经做了」当作授权依据。

## 三、系统权限与屏幕内容

1. 助手的能力依赖系统级权限：无障碍服务（读取界面节点、模拟点击）、截屏与屏幕帧读取、通知使用权、剪贴板、文件访问、终端与 Root/Shizuku、相机/相册/麦克风、定位等。
2. 一旦授予无障碍或屏幕读取，助手「看见」的是整块屏幕，而不只是 Eta 的界面。屏幕上可能出现别人的聊天记录、身份证号、银行卡、病例、行踪轨迹等属于你或属于第三方的敏感个人信息。
3. 我们按场景调用：只有在你发起任务、且任务确实需要时才读取对应能力，任务结束即停止；不做与任务无关的持续后台采集。每类权限的用途、触发时机、是否离开本机，见《隐私说明》。
4. 你不得让助手处理你无权处分的他人个人信息，也不得把无权使用的数据输入给助手。因输入内容引发的权利纠纷由你承担。
5. 你可以随时在系统设置里关闭任意一项权限；关闭后对应功能不可用，但不影响其余功能。

## 四、数据用途

1. 处理目的只有一个：让你能正常使用测试版，并让出现的问题可复现——包括会话内容、工具调用记录、崩溃与诊断日志。
2. 这些数据不用于模型微调，也不用于新模型训练。如果将来提出这类用途，会单独重新征询你的同意，不会用这一份协议覆盖。
3. 你可以在「设置 → 测试与隐私」随时撤回同意，撤回后助手立即停止运行。

## 五、责任边界、撤回方式与禁止行为

1. 服务可用性：我们对自己可控的部分（安装包完整性、服务端接口可用性）负责。
2. AI 输出质量：我们承担的是披露与告知义务，不是对输出正确性的保证。
3. 责任分层：你直接依赖未经核验的输出而造成损失的，我们的责任设有较低上限；经你或他人人工核验后使用仍发生损失的，按具体情形认定。法律强制规定不可免除的责任，不因本条而免除。
4. 撤回：你可以随时在「设置 → 测试与隐私」撤回全部同意，并删除本地测试数据。撤回后我们停止对应的后续处理，不影响撤回前已经进行的处理。
5. 反馈与改进成果：你提交的问题反馈、建议、截图说明，我们可以无偿用于产品改进，不因此产生共有权利、报酬或署名请求。
6. 禁止行为：公开分享测试包、内部截图、功能细节与路线图；对产品进行逆向工程、破解、未授权的安全测试；把测试包转交给第三方；用助手实施侵害他人权益的行为。
