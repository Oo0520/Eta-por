# Eta 测试版 · 隐私说明

本说明与《测试协议与免责声明》同时生效，逐项说明测试版会接触哪些数据、为什么接触、什么时候接触、会不会离开这台设备。

## 一、我们处理哪些数据

1. 会话数据：你输入的文本、语音转写、图片与附件，助手的回复、工具调用参数与结果。
2. 屏幕内容：任务运行中读取的界面节点文本（按钮名、列表项、输入框内容）与可选截图。
3. 设备信息：系统版本、机型、Root/LSPosed 状态、已安装应用列表（仅用于能力判断，不上传名单）。
4. 诊断数据：崩溃堆栈、耗时、错误码，用于定位问题。
5. 模型与账号配置：模型选择、MCP 服务地址、GitHub 账号等，存放在应用私有目录。

## 二、系统权限逐项说明

无障碍服务｜读取当前界面结构与文本、模拟点击滑动｜只有在你发起任务、任务正在运行时｜节点文本随对话上下文上传
屏幕读取与截屏｜让助手看见画面、定位坐标｜任务运行中按需调用，另有总开关可关闭｜图像会上传（默认关闭截图上传）
通知使用权｜读取通知摘要，用于提醒与自动化触发｜常驻监听｜摘要随对话上下文上传
剪贴板｜读写文本，用于粘贴与复制｜你主动调用或任务需要时｜内容会上传
文件与存储｜读写工作区、导出附件｜你主动调用时｜所选文件内容会上传
终端与 Linux 环境｜执行命令、访问 Root/Shizuku 能力｜你主动调用时｜命令与输出会上传
相机/相册/麦克风｜拍照、选图、语音输入｜你主动调用时｜所选内容会上传
定位｜回答与时间地点相关的问题｜你提问涉及位置时｜坐标会上传
已安装应用列表｜判断能调用哪些应用、启动目标应用｜启动时读取｜不上传完整名单

## 三、数据保存与删除

1. 会话与配置默认保存在本机应用私有目录（测试版是独立目录，与正式版互不可见）。
2. 诊断日志按容量滚动覆盖，保留最近若干天的记录。
3. 你可以在「设置 → 测试与隐私」删除本地测试数据；删除后本机不再保留对应内容。
4. 测试期间收集的数据不用于模型训练，因此不存在「已经进入模型参数、无法精准撤回」的情况；对话记录与附件都可以按上面的方式删除。

## 四、第三方与数据出境

1. 模型推理由你自行配置的模型服务商提供。你在设置里填了哪家，数据就会发给哪家，适用该服务商的隐私政策。
2. MCP 服务、GitHub 等第三方连接由你主动配置并授权，连接目标与传输内容由你选择。
3. 我们不额外把你的数据转卖给第三方，也不用于本说明之外的用途。
4. 若模型服务商位于境外，相关数据会出境；是否使用境外服务由你在模型设置中决定。

## 五、你的权利与撤回渠道

1. 知情与查阅：本页面随时可重读，路径是「设置 → 测试与隐私 → 查看全文」。
2. 单独同意：屏幕内容中可能出现的敏感个人信息（证件、金融、健康、行踪等）是单独勾选，不与其他同意捆绑。
3. 撤回同意：「设置 → 测试与隐私 → 撤回全部同意」。撤回后运行时服务随即停止，下次启动会重新征询。
4. 权限撤回：系统设置里逐项关闭；关闭即停止对应采集。
5. 删除数据：「设置 → 测试与隐私 → 删除本地测试数据」。
6. 投诉与联系：通过项目仓库的 issue 渠道反馈；我们会在合理期限内答复。
